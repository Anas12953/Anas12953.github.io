Desert Knights — Parents

A classroom, connected.

A parent portal for Al Ebtehal Kindergarten, bringing classroom updates and learning resources into one place.

My role
Design and project direction, with AI-assisted implementation
Tools & technology
Web interface · Framework: awaiting confirmation
Context
Web experiences / 2026
01

The need

Parents need a clear place to find the information shared by their child’s class. Desert Knights was designed for the Al Ebtehal Kindergarten classroom community.

02

The approach

I worked on a parent-facing experience around classroom updates, weekly plans, educational activities and other class information. The project taught me to think about a real audience, rather than only how a page looks.

03

My contribution

I designed the portal for the class and directed its development and refinements, using AI assistance as part of the build process.

04

What I learned

Navigation and clarity matter when a site is part of someone’s routine. A useful school project has to make the next step easy to understand.

Exact framework and backend technologies have not been confirmed; this case study does not attribute an unverified stack.
